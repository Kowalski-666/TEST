STUDENT MANAGEMENT SYSTEM  (Java Swing)
=======================================
Requires: JDK 8 or newer.

HOW TO RUN (command line)
  javac *.java
  java Main

HOW TO RUN (NetBeans / Eclipse / IntelliJ)
  Create a new Java project, copy all .java files into the src folder (default package), run Main.java.

LOGIN
  admin / admin123        registrar / reg123

DATA STORAGE
  CSV files are auto-created in the "data" folder on first run (22 students, 10 subjects, enrollments, users).
  Delete the "data" folder to reset to the sample data.
